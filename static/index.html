K 線型態學基礎

「型態為王，大道至簡」 — 屏除繁雜指標，專注 K 線型態與量價結構。所有市場資訊最終都會反映在價格圖形上。

12 種經典型態

🔴 底部型態

  • V 字底 — 急跌急升
  • U 字底 — 緩跌緩升
  • 碗型底 — 圓弧底
  • 雙重底 (W) — 兩次低點相近

🔵 頭部型態

  • M 字頭 — 兩個高點
  • 雙頂 — 同高度頂部
  • 尖頂 — 快速上下
  • 圓頂 — 緩慢翻轉

🟡 中繼型態

  • 三角形 — 收斂整理
  • 旗形 — 平行整理
  • 矩形 — 區間震盪
  • 楔形 — 漸收斂

底部反轉的關鍵訊號

  1. 價格跌至前低附近但未有效跌破
  2. 第二低點略高於第一低點（不能更低）
  3. 快速反轉向上 + 成交量配合
  4. 突破中間高點（頸線）= 確認反轉
  5. 停損設在第二低點下方

假突破 vs 真突破

假突破真突破
量能無量或縮量明顯放量
後續馬上回到區間持續推進
回測跌破不破
應對反向操作順勢加碼

操盤心法

  • 📌 認賠比對更重要 — 嚴格執行停損
  • 📌 不追高、不殺低
  • 📌 風險報酬比至少 1:2
  • 📌 操作不需盯盤，等待最佳時機
  • 📌 計畫你的交易，交易你的計畫

漲跌測幅公式

上升目標 = 突破點 + (突破點 - 前低)
下跌目標 = 突破點 - (前高 - 突破點)

🔥 進階方法論（中文技術分析學派重點）

以下重點整理自多個中文技術分析公開講座，為通用市場觀點。

🎯 核心圓型訊號

訊號描述操作意義
破底翻價格跌破前低後迅速反彈，未有效跌破築底結構成立 → 做多訊號
假突破價格短暫突破關鍵壓力位後迅速回落逆勢訊號 → 高檔逃頂
量價背離價格創高但量能未同步上漲動能不足 → 警訊
主力攻擊成本價格突破主力成本區且量能配合跟單點（買進）
滿足點（多/空）型態頂部上升距離 = 多空滿足目標出場/減碼參考

📈 進場檢查清單

  1. 趨勢方向 — 高低點是否墊高？上升中才進場。
  2. 型態訊號 — W 底 / 破底翻 / 頭肩底出現。
  3. 量能變化 — 突破需要量能配合（量先價行）。
  4. 主力成本 — 價格穩定站上主力平均成本。
  5. 頸線確認 — 突破頸線來確認翻轉。

📉 出場 / 停損規則

  • 頸線跌破 → 頭部完成，立即出場
  • 達型態滿足點 → 進行減碼
  • 出現假突破 → 偏向出場或反向操作
  • 連續 2 次操作失誤 → 提高警覺，減倉
  • 連續 3 次操作失誤 → 收手，離場休息
  • 高檔逐步減碼 → 不要勇於接落下的刀

💰 資金管理

  • 低檔可提高倉位，高檔逆向逐步減碼
  • 不要 All-in、也不要一次出完：分批進出場平均成本
  • 以型態計算滿足點設定停利，不貪心交易
  • 設停損：第二低點下方，跌破則出

🧠 心態紀律

  • 不要凹單（要抱就抱漲）：買進下跌不加碼，先認賠
  • 不要報復性交易：輸了不要想快速賺回來
  • 量價結構是主力足跡：量是真的，價可以騙人
  • 技術面反映基本面：不需要內線，所有資訊都在圖上

K 線型態學學習資源

以下為公開可取得的技術分析學習資源，供進階研究參考。

📚 經典書籍

  • 《Technical Analysis of Stock Trends》 — Edwards & Magee，技術分析的鼻祖之作
  • 《Encyclopedia of Chart Patterns》 — Thomas Bulkowski，型態圖鑑
  • 《Japanese Candlestick Charting Techniques》 — Steve Nison，K 線之父
  • 《股票作手回憶錄》 — Edwin Lefèvre，操盤心法

🎯 學習路徑建議

  1. 第一階段：型態識別先認得底部、頭部、中繼三大類，能在圖上指出位置
  2. 第二階段：量價結構學會看放量、縮量與價格的搭配（量先價行）
  3. 第三階段：突破與假突破區分有效突破，學會用回測確認
  4. 第四階段：實戰演練用本工具掃個股，把判讀和事後結果對照
  5. 第五階段：心態紀律停損執行、風險控管、不報復性交易
