# 型態學波段分析器 📈

用 K 線型態 + 量價結構分析台股 / 美股的網站。

## ✨ 功能

- **K 線圖** — 台積電 / NVIDIA / 任何台美股代號
- **型態學分析**
  - 趨勢判斷（高低點結構）
  - 雙底 / 雙頂 / 底部反轉 偵測
  - 量價結構（爆量/放量/縮量 × 上漲/下跌/盤整）
  - 操作觀察
- **學習頁** — 12 種經典型態解說
- **學習路徑** — 五階段循序漸進

## 🚀 啟動

```bash
cd /Users/alanishu/.openclaw/workspace/pattern-web
```

## 🎓 型態學核心

### 12 種經典型態
| 類別 | 招式 |
|------|------|
| 🔴 底部 | V 底 · U 底 · 碗型底 · 雙重底 |
| 🔵 頭部 | M 頭 · 雙頂 · 尖頂 · 圓頂 |
| 🟡 中繼 | 三角 · 旗形 · 矩形 · 楔形 |

### 底部反轉訊號
1. 跌至前低附近但未有效跌破
2. 第二低點略高於第一低點
3. 快速反轉 + 量能配合
4. 突破中間高點（頸線）= 確認
5. 停損設在第二低點下方
